# Compute p-value for perplexity via permutation

Compute p-value for perplexity via permutation

## Usage

``` r
perplexityPermute(spe, pm = NA, pm_cols = NA, n_perm = 1000)
```

## Arguments

- spe:

  A SpatialExperiment object.

- pm:

  Optional. The probability matrix.

- pm_cols:

  The colnames of probability matrix. This is requires for
  SpatialExperiment input. Assuming that the probability is stored in
  the colData.

- n_perm:

  Integer number. The number of permutation. 1000 by default.

## Value

A SpatialExperiment object. Calculated P-value and adjusted P-value are
saved as columns in the colData of the SpatialExperiment object. P-value
and adjusted P-value are calculated based on permutation test and
Benjamini Hochberg correction.
